해줄 것:
1. 환경 확인 먼저 — 디스크 용량(20GB 필요), GPU 유무.
   GPU는 추론 속도용이지 학습용이 아니야.
2. poc/ 에 Python 환경 세팅 (uv 권장)
3. 벤치마크 스크립트:
   - 모델 3종: Grounding DINO Tiny, OWLv2, YOLO-World
   - 프롬프트 4종(glasses / eyeglasses / spectacles / a pair of eyeglasses)
     + 임베딩 앙상블
   - 네거티브 어휘(keys, phone, scissors, pen, remote control, cup) 동시 투입
   - 신뢰도 임계값 스윕
   - 결과 CSV 출력
4. 측정은 프레임 단위 recall이 아니라 세션 단위 성공률 (기획서 11절)
5. 0a(FP32 상한선) 먼저, 0b(ONNX FP16 배포 포맷)는 그 다음.
   Go/No-Go 판정은 0b 숫자로 한다.

모델 크기도 측정 항목이야. 목표 100MB 이하.
라이선스는 Apache-2.0 우선(Grounding DINO, OWLv2). YOLO-World는 GPL이라 폴백용.

## 촬영 체크리스트 (내가 할 일)

### 1단계 — 사진 3장

모델이 아예 못 잡는지만 본다. 통계 아님.

- [ ] 책상 위, 얼굴 없이 안경만
- [ ] 이불/소파 위
- [ ] 바닥

0/3이면 거기서 판단하고 다음으로 안 넘어간다.

### 2단계 — 30초 스윕 영상 3개 (1단계 통과 시에만)

폰 들고 방을 훑으면서 녹화. **실제 쓸 때처럼** 천천히.

- [ ] 방 A (책상 있는 곳)
- [ ] 방 B (침대/소파)
- [ ] 저조도 또는 역광 조건

한 영상에 안경이 한 번은 화면에 들어오게. 영상 1개당 프레임 60~90장 나온다.

> `data/` 는 .gitignore 에 있어서 커밋되지 않는다 (집 내부 영상이므로).
